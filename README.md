#  Project Overview

The **Mobile Sales Dashboard** is an interactive Business Intelligence solution developed using **Microsoft Power BI** to analyze mobile phone sales performance across different brands, cities, payment methods, customers, and time periods.

This dashboard enables business users to monitor KPIs, identify sales trends, compare current performance with previous periods, evaluate customer behavior, and analyze product performance through interactive reports.

---

#  Business Objectives

- Monitor overall mobile sales performance.
- Analyze sales across different brands and models.
- Track Month-to-Date (MTD) sales.
- Compare current sales with the Same Period Last Year (SPLY).
- Understand customer purchasing behavior.
- Analyze preferred payment methods.
- Identify top-performing cities and products.
- Enable data-driven business decisions.
